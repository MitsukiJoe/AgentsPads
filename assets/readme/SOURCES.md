# README 图标来源

- `language.svg`：字形来自 [Tabler Icons v3.46.0 的 language 图标](https://github.com/tabler/tabler-icons/blob/v3.46.0/icons/outline/language.svg)，缩放后改为白色，添加蓝色高光底牌；底牌参考 Tabler Flags Shiny 的圆角、渐变和边框。属于本项目组合改版，不是 Tabler 官方提供的语言图标成品。
- `download-zh.svg`、`download-en.svg`：内嵌 [Tabler Icons v3.46.0 的 download 图标](https://github.com/tabler/tabler-icons/blob/v3.46.0/icons/outline/download.svg)，改为白色，并添加蓝色全圆角背景与中英文文字。
- Tabler Icons 使用 MIT 许可，完整声明见 [LICENSE-tabler.txt](LICENSE-tabler.txt)。
- 中美国旗直接引用 [Tabler Flags](https://github.com/tabler/tabler-flags) 的 Shiny 款，固定 npm 版本 `@tabler/flags@0.1.1`，通过 jsDelivr 展示，不在仓库保存国旗图片。语言底牌参考同一版本的 Shiny 装饰。MIT 许可见 [LICENSE-tabler-flags.txt](LICENSE-tabler-flags.txt)。
  - [中国国旗](https://cdn.jsdelivr.net/npm/@tabler/flags@0.1.1/dist/shiny/china.svg)
  - [美国国旗](https://cdn.jsdelivr.net/npm/@tabler/flags@0.1.1/dist/shiny/united-states.svg)

语言图标和下载按钮保存在仓库内。信息徽章继续使用 Shields.io。

- `technical-zh.svg`、`technical-en.svg`：本项目制作的技术文档入口按钮，沿用下载按钮的蓝色全圆角样式，文字和箭头不使用第三方图标。
